3. STUDENT SCHEDULES
Build a Schedule system with three input methods:

a) PULL FROM SCHOOL APP
- If user has connected Aula or another school app, 
  automatically pull their timetable via 
  SchoolProvider.getSchedule()
- Display today's classes in the briefing

b) FILE IMPORT
- User uploads a PDF or CSV of their timetable
- Send file content to Groq (llama-3.3-70b-versatile) 
  with prompt: "Extract this school timetable into a 
  structured JSON format with day, start_time, end_time, 
  subject, room fields"
- Save extracted schedule to Supabase table: schedules
  columns: id, user_id, day_of_week, start_time, 
  end_time, subject, room, created_at
- Show today's classes in the daily briefing

c) MANUAL ENTRY
- Simple form in settings to add classes manually
- Fields: day of week, start time, end time, 
  subject, room (optional)
- Save to same schedules Supabase table
- User can edit or delete individual classes

SUPABASE — NEW TABLES NEEDED
Run these in Supabase SQL editor before starting:

create table schedules (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references users(id) on delete cascade,
  day_of_week text not null,
  start_time text not null,
  end_time text not null,
  subject text not null,
  room text,
  created_at timestamp with time zone default now()
);

create table spotify_connections (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references users(id) on delete cascade,
  access_token text not null,
  refresh_token text not null,
  created_at timestamp with time zone default now()
);
